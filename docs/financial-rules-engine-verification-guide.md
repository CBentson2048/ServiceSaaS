## 4. Required local prerequisites

   ⚠️ **On macOS/Homebrew, `/usr/local/bin/initdb` may come from the `libpq` keg, which has no server.** It fails with `program "postgres" is needed by initdb but was not found`. Use the full keg path:
   ```
   /usr/local/opt/postgresql@18/bin
   ```

   Verify with: `ls /usr/local/opt/postgresql@18/bin/postgres`

## 5. Environment variables

```bash
export PGBIN=/usr/local/opt/postgresql@18/bin   # adjust for your install
export PGHOST=/tmp/qpg
export PGPORT=55432
export PGUSER=pgcheck
export LC_ALL=C
export LANG=C
```

Two of these are load-bearing on macOS, both learned the hard way:

- **`LC_ALL=C` / `LANG=C`** — without them the server dies at startup with `FATAL: postmaster became multithreaded during startup`.
- **`PGHOST=/tmp/qpg`** — the Unix socket path has a **103-byte limit**. A cluster under a long project or scratch path fails with `Unix-domain socket path is too long`. Keep it short.

Port `55432` is deliberately not `5432`, so this never collides with a local Postgres you already run.

## 6. Exact commands to run

### Step 0 — Create the scratch cluster

```bash
rm -rf /tmp/qpg && mkdir -p /tmp/qpg
$PGBIN/initdb -D /tmp/qpg/data -U pgcheck --auth=trust
$PGBIN/pg_ctl -D /tmp/qpg/data -o "-p 55432 -k /tmp/qpg" -l /tmp/qpg/server.log start
sleep 3
$PGBIN/psql -d postgres -tAc "select 'CLUSTER_UP ' || current_setting('server_version')"
```

Expect: `CLUSTER_UP 18.3` (or your version). If the server did not start, read `/tmp/qpg/server.log`.

### Step 0b — Supabase roles and stubs

Without these, ~38 migrations fail on `GRANT` statements and migration `0001` fails on `auth.uid()`. This is a harness gap, not a schema defect.

```bash
$PGBIN/psql -d postgres -c "create role anon nologin"
$PGBIN/psql -d postgres -c "create role authenticated nologin"
$PGBIN/psql -d postgres -c "create role service_role nologin"

cat > /tmp/qpg/prelude.sql <<'SQL'
create schema if not exists auth;
create table if not exists auth.users (id uuid primary key, email text, raw_user_meta_data jsonb, encrypted_password text, created_at timestamptz default now());
create or replace function auth.uid() returns uuid language sql stable as $f$ select nullif(current_setting('request.jwt.claim.sub', true), '')::uuid $f$;
create or replace function auth.role() returns text language sql stable as $f$ select nullif(current_setting('request.jwt.claim.role', true), '') $f$;
create schema if not exists storage;
create table if not exists storage.buckets (id text primary key, name text, public boolean, file_size_limit bigint, allowed_mime_types text[]);
create table if not exists storage.objects (id uuid primary key default gen_random_uuid(), bucket_id text, name text, owner uuid, metadata jsonb);
insert into auth.users (id, email) values ('33333333-3333-3333-3333-333333333333','a@t.com') on conflict do nothing;
SQL
```

The `auth.users` row matters: `core.user_profiles.id` has a foreign key to it, so test fixtures cannot insert a staff member without it.

### Part D — Service Revenue Target rename regression

**D1 — Database columns renamed, old names gone:**

```bash
$PGBIN/psql -d qv -tAc "select column_name from information_schema.columns where table_schema='core' and table_name='staff_profiles' and column_name like '%target%' order by 1"
```
Expect exactly:
```
service_revenue_target_amount
service_revenue_target_mode
```
**Any row containing `performance_target` is a failure.**

**D2 — Enum renamed:**

```bash
$PGBIN/psql -d qv -tAc "select t.typname from pg_type t join pg_namespace n on n.oid=t.typnamespace where n.nspname='core' and t.typtype='e' and t.typname like '%target_mode%'"
```
Expect exactly one row: `staff_service_revenue_target_mode_enum` — and **not** `staff_performance_target_mode_enum`.

⚠️ The `t.typtype='e'` filter is required. Without it PostgreSQL also returns
`_staff_service_revenue_target_mode_enum` — the auto-generated **array type**
that accompanies every enum. That leading-underscore row is normal and is not a
duplicate or a failed rename.

**D3 — Enum values unchanged (rename must not alter data):**

```bash
$PGBIN/psql -d qv -tAc "select enumlabel from pg_enum e join pg_type t on t.oid=e.enumtypid where t.typname='staff_service_revenue_target_mode_enum' order by enumsortorder"
```
Expect: `flat`, `pro_rated`.

**D4 — No stale references in code:**

```bash
cd /path/to/sheer-platform
grep -rn "performance_target\|performanceTarget\|PerformanceTarget\|PERFORMANCE_TARGET" \
  --include="*.ts" --include="*.tsx" . | grep -v node_modules | grep -v "/dist/"
```
Expect: **no output, and exit code 1.**

⚠️ `grep` exits `1` when it finds nothing. For this check that is the **pass**
condition — an exit code of `0` would mean stale references still exist. Do not
treat the non-zero exit as a failure, and do not wrap this in a script that
aborts on non-zero exit.

**D5 — Types compile:**

```bash
pnpm --filter @sheer/domain build      # must succeed; web reads domain from dist
cd apps/api && npx tsc --noEmit        # expect no output
cd ../web && npx tsc -b                # NOTE: -b, not --noEmit (see below)
```

⚠️ `apps/web` uses a solution-style tsconfig, so `tsc --noEmit` silently checks nothing. **`tsc -b` is the only meaningful check there.**

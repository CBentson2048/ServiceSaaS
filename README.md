# Sheer Platform

Multi-location salon operations platform for mobile, web, and backend services.

## Apps
- `apps/mobile` - React Native app for staff/client experiences
- `apps/web` - web dashboard for owner/manager
- `apps/api` - backend API and business logic

## Core domains
- Auth, roles, tenancy
- Booking and deposits
- CRM and visit history
- Rota and availability
- Sheer Lab BLE formula workflows
- Billing and inventory
- Commission and dashboard

## Environments
- development
- staging
- production

- React Native
- React / Next.js
- Node.js / NestJS
